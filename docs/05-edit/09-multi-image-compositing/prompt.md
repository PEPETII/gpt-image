# 5.9 Multi-Image Referencing and Compositing Prompt

Source: https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide

## Official prompt 1

```text
Place the dog from the second image into the setting of image 1, right next to the woman, use the same style of lighting, composition and background. Do not change anything else.
```

## 中文翻译

将第二张图片中的狗放入第一张图片的场景中，紧挨着女性；使用与第一张图相同的光线、构图和背景风格。不要改变任何其他内容。

## 可替换变量

可替换 Image 1/2 的角色、要移动的对象和目标位置；明确每张图的来源关系。
