# 5.3 Drawing → Image (Rendering) Prompt

Source: https://developers.openai.com/cookbook/examples/multimodal/image-gen-models-prompting-guide

## Official prompt 1

```text
Turn this drawing into a photorealistic image.
Preserve the exact layout, proportions, and perspective.
Choose realistic materials and lighting consistent with the sketch intent.
Do not add new elements or text.
```

## 中文翻译

将这幅图画转换成照片级写实图像。保持准确的布局、比例和透视；根据草图意图选择真实材质和光线；不要添加新的元素或文字。

## 可替换变量

可替换草图、目标媒介、材质和光线；布局、比例和透视属于保持项。
