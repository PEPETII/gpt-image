# 第1章：引言 | Introduction

> 本章介绍 OpenAI 图像生成模型的概况、核心参数、常用尺寸以及模型选择建议。

---

## 1.1 OpenAI 图像模型概述

OpenAI 提供了一系列强大的图像生成与编辑模型，其中 **`gpt-image-2`** 是最新的生产级模型，具备卓越的图像生成质量、文字渲染能力和编辑精度。

OpenAI 图像模型支持两种核心工作模式：

| 模式 | 说明 | API 方法 |
|------|------|----------|
| **Generate**（生成） | 从文本提示词生成全新图像 | `client.images.generate()` |
| **Edit**（编辑） | 基于输入图像进行修改和编辑 | `client.images.edit()` |

生成模式适用于从零创建图像，编辑模式适用于在现有图像基础上进行风格迁移、物体替换、场景修改等操作。

---

## 1.2 模型参数表

以下是 OpenAI 图像模型支持的全部参数：

### model — 模型选择

| 参数值 | 说明 |
|--------|------|
| `"gpt-image-2"` | **最新生产级模型**，推荐大多数场景使用，质量最高 |
| `"gpt-image-1.5"` | 上一代增强模型，在 `gpt-image-1` 基础上改进 |
| `"gpt-image-1"` | 第一代标准模型 |
| `"gpt-image-1-mini"` | 轻量级模型，速度最快，适合对延迟敏感的场景 |

### quality — 输出质量

| 参数值 | 说明 |
|--------|------|
| `"high"` | 最高质量，适合需要精细文字渲染和细节的场景，延迟较高 |
| `"medium"` | 中等质量，平衡质量与速度，适合大多数场景 |
| `"low"` | 最低质量，速度最快，适合快速预览和迭代 |

### input_fidelity — 输入图像保真度（仅 Edit 模式）

| 参数值 | 说明 |
|--------|------|
| `"high"` | 高保真度，最大程度保留输入图像的细节，适合精细编辑 |
| `"medium"` | 中等保真度，平衡保留与创新 |
| `"low"` | 低保真度，允许模型对输入图像进行较大幅度的改动 |

### size — 图像尺寸

图像尺寸使用 `"宽x高"` 格式指定，遵循以下规则：

| 约束 | 说明 |
|------|------|
| 最大边长 | 单边不超过 **3840px** |
| 对齐要求 | 宽度和高度都必须是 **16 的倍数** |
| 长宽比 | 宽高比不超过 **3:1** |

### n — 生成变体数量

| 说明 |
|------|
| 指定每次 API 调用生成的图像变体数量，可用于获取同一提示词下的多个不同结果 |

### background — 背景设置

| 参数值 | 说明 |
|--------|------|
| `"opaque"` | 生成不透明背景的图像（默认背景可能包含透明区域） |

## 1.3 常用尺寸参考表

以下是推荐使用的常用尺寸，均已满足 16 的倍数和长宽比约束：

| 类型 | 尺寸 | 长宽比 | 适用场景 |
|------|------|--------|----------|
| **Square**（正方形） | `1024x1024` | 1:1 | 社交媒体头像、Logo、产品图 |
| **Portrait**（竖版） | `1024x1536` | 2:3 | 手机壁纸、海报、人物肖像 |
| **Landscape**（横版） | `1536x1024` | 3:2 | 桌面壁纸、横幅广告、风景照 |
| **Wide**（宽屏） | `1536x864` | 16:9 | 网站横幅、视频封面、演示文稿 |
| **2K**（高清） | `2560x1440` | 16:9 | 高清壁纸、印刷品、大尺寸展示 |

> **提示**：你也可以使用其他自定义尺寸，只要满足单边 < 3840px、两边为 16 的倍数、长宽比不超过 3:1 的约束即可。

## 1.4 模型选择建议

根据不同的使用场景，推荐以下模型和参数组合：

### 通用推荐

| 场景 | 推荐模型 | quality | 说明 |
|------|----------|---------|------|
| **大多数场景** | `gpt-image-2` | `"medium"` | 最佳质量与速度平衡 |
| **精细文字渲染** | `gpt-image-2` | `"high"` | 小文本、标签、海报中的文字 |
| **快速预览/迭代** | `gpt-image-2` | `"low"` | 快速查看效果，降低成本 |
| **速度优先** | `gpt-image-1-mini` | `"medium"` | 对延迟极度敏感的场景 |
| **精细编辑** | `gpt-image-2` | `"medium"` + `input_fidelity="high"` | 保留输入图像细节 |

### Generate vs Edit 选择

| 需求 | 推荐模式 | 说明 |
|------|----------|------|
| 从零创建图像 | **Generate** | 使用文本提示词生成全新图像 |
| 修改现有图像 | **Edit** | 基于输入图像进行精确修改 |
| 风格迁移 | **Edit** | 保留内容结构，改变艺术风格 |
| 物体替换 | **Edit** | 替换图像中的特定物体 |
| 多图合成 | **Edit** | 支持多张输入图像的合成操作 |

---

## 1.5 小结

- `gpt-image-2` 是当前最强大的图像生成模型，适合绝大多数场景
- `quality` 参数控制输出质量与延迟的平衡，`"medium"` 是通用推荐值
- `input_fidelity="high"` 是精细编辑的关键参数
- 图像尺寸灵活，但需满足对齐和长宽比约束
- 速度敏感场景可使用 `quality="low"` 或 `gpt-image-1-mini`
