# 光照天气变换 | Lighting & Weather Transformation

> 章节：5.6 | 分类：编辑 (Edit)

---

## 提示词 / Prompt

```text
Make it look like a winter evening with snowfall.
```

### 中文翻译

```
让它看起来像一个有降雪的冬夜。
```

---

## 关键技巧 / Key Tips

仅改变环境条件——光照方向/质量、阴影、氛围、降水和地面湿度；同时保持身份、几何、相机角度和物体位置不变。使用 `input_fidelity="high"` 以在较大场景编辑时保持原始图像的忠实度。

## API 参数建议 / Recommended Parameters

| 参数 | 值 | 说明 |
|------|-----|------|
| input_fidelity | high | 高保真度，保持原始图像忠实度 |
| size | 1536x1024 | 横版构图，适合风景和场景类图像 |

## 适用场景 / Use Cases

房地产照片优化、影视预览、季节性营销素材
