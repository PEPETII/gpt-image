# 营销创意带文字 | Marketing Creatives with Text

> 章节：5.5 | 分类：编辑 (Edit)

---

## 提示词 / Prompt

```text
Create a realistic billboard mockup of the shampoo on a highway scene during sunset.
Billboard text (EXACT, verbatim, no extra characters):
"Fresh and clean"
Typography: bold sans-serif, high contrast, centered, clean kerning.
Ensure text appears once and is perfectly legible.
No watermarks, no logos.
```

### 中文翻译

```
创建一个洗发水在高速公路日落场景中的逼真广告牌模型。
广告牌文字（精确，逐字，不多任何字符）：
"Fresh and clean"
排版：粗体无衬线字体，高对比度，居中，字距清晰。
确保文字只出现一次，完全清晰可读。
无水印，无标志。
```

---

## 关键技巧 / Key Tips

将精确文案放在引号中，要求逐字渲染（无多余字符）；描述放置位置和字体风格；使用"EXACT, verbatim, no extra characters"等强调词。如果文字保真度不完美，保持提示词严格并迭代微调。

## API 参数建议 / Recommended Parameters

| 参数 | 值 | 说明 |
|------|-----|------|
| quality | high | 高质量输出，确保文字清晰可读 |
| size | 1536x1024 | 横版构图，适合广告牌和场景展示 |

## 适用场景 / Use Cases

广告创意、社交媒体海报、品牌营销素材
