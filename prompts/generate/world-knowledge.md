# 世界知识 | World Knowledge

> 章节：4.4 | 分类：生成 (Generate)

---

## 提示词 / Prompt

```text
Create a realistic outdoor crowd scene in Bethel, New York on August 16, 1969. Photorealistic, period-accurate clothing, staging, and environment.
```

### 中文翻译

```
创建一个1969年8月16日纽约Bethel的逼真户外人群场景。照片级写实，时代准确的服装、舞台布置和环境。
```

---

## 关键技巧 / Key Tips

利用GPT的世界知识，指定具体的时间、地点和历史事件；要求"时代准确"确保细节可信。

## API 参数建议 / Recommended Parameters

| 参数 | 值 | 说明 |
|------|-----|------|
| quality | "high" | 高质量模式，适合复杂场景和人群细节 |
| size | "1536x1024" | 横向尺寸，适合户外场景的广角展示 |

## 适用场景 / Use Cases

历史场景还原、文化场景生成、教育插图
