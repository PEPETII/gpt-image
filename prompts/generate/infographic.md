# 信息图表 | Infographic

> 章节：4.1 | 分类：生成 (Generate)

---

## 提示词 / Prompt

```text
Create a detailed Infographic of the functioning and flow of an automatic coffee machine like a Jura. From bean basket, to grinding, to scale, water tank, boiler, etc. I'd like to understand technically and visually the flow.
```

### 中文翻译

```
创建一张详细的咖啡机（如Jura）功能和流程信息图。从豆仓，到研磨，到秤，水箱，锅炉等。我想从技术和视觉上理解整个流程。
```

---

## 关键技巧 / Key Tips

像写教学设计简报一样描述需求，明确列出需要展示的组成部分；使用 `quality="high"` 处理密集标签和图表。

## API 参数建议 / Recommended Parameters

| 参数 | 值 | 说明 |
|------|-----|------|
| quality | "high" | 高质量模式，适合处理密集标签和图表细节 |
| size | "1536x1024" | 横向尺寸，适合信息图表的宽幅展示 |

## 适用场景 / Use Cases

技术流程图、产品功能说明、教育信息图
