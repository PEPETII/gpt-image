# 提示词最佳实践

以下清单提炼自官方 Cookbook 第 2 章及 4–6 章用例。完整说明以对应章节为准。

## 写提示词

- [ ] 按“背景/场景 → 主体 → 关键细节 → 约束”组织复杂请求；
- [ ] 用具体的材质、形状、纹理、媒介、色彩和光线替代“高级”“好看”等抽象词；
- [ ] 写明景别、视角、主体位置、留白和视觉层级；
- [ ] 照片级任务直接写 `photorealistic`，并补充自然纹理和不完美细节；
- [ ] 图片内文字使用引号，标注 `EXACT, verbatim`、出现次数、位置和字体方向；
- [ ] 信息图、UI、图表和幻灯片避免小字、歧义箭头和无关装饰；
- [ ] 对历史或事实场景写地点、日期、时代服装、建筑和工具，不添加现代物件。

## 编辑与多图

- [ ] 用 `Change` 指明唯一要改变的内容；
- [ ] 用 `Preserve` 列出身份、脸部、体型、姿势、几何、构图、标签、背景和光线；
- [ ] 用 `Do not change` 兜底禁止额外修改；
- [ ] 多图输入使用 Image 1、Image 2 和明确角色，保持输入顺序与 prompt 一致；
- [ ] 合成时要求匹配尺度、透视、光线方向、阴影、色温、景深和图像纹理；
- [ ] `gpt-image-2` 图片输入自动按高保真处理，不添加 `input_fidelity`。
- [ ] 如需透明背景，使用 `background="transparent"` 并将格式设为 `png` 或 `webp`，且明确要求没有风景或不想要的阴影。

## 迭代

- [ ] 先生成干净基础版本，再一次只修改一个维度；
- [ ] 关键保持项在每轮请求中重复，避免身份、布局或背景漂移；
- [ ] 文字不准确时只修正文案、字距、位置或对比度，不重写无关内容；
- [ ] 复杂工作流先生成角色/产品锚点，再将其作为下一步输入；
- [ ] 质量设置按官方建议选择：草稿先试 `low`，一般任务使用 `medium`，密集文字或精细画面比较 `high`。

## 原创与安全

- [ ] Logo、手办和角色设计写明 `Original design only`、`No trademarks`；
- [ ] 不要求仿制现有品牌或受版权保护角色；
- [ ] 不把一次生成成功、精确文字或身份一致性写成保证；
- [ ] 不在提示词或示例中写入 API Key。
